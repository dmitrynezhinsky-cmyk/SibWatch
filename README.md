# Лендинг «Ремонт часов в Новосибирске» — Сибвоч (SibWatch)

Статический лендинг, оптимизированный под рекомендации ИИ-ассистентов (Алиса, ChatGPT, DeepSeek, Perplexity). Оформлен в фирменном стиле основного сайта `sibwatch.ru`: синий `#0078b3`, красный акцент `#e03239`, тёмный `#1a1b25`, фон `#f8f8f8`, шрифт Ubuntu (основной сайт использует NeoSansCyr/Ubuntu). Тема — **только ремонт часов**.

## Отзывы и авторские права (важно)

Коротко: **публиковать выдуманные отзывы и завышенный рейтинг нельзя** (недостоверная реклама, ФЗ «О рекламе», ст. 5), а **копировать чужие отзывы с Яндекс.Карт и 2GIS без разрешения — рискованно**: текст отзыва охраняется как авторское произведение, плюс это персональные данные автора.

Текущее состояние (безопасное для публикации):

- Отдельного раздела «Отзывы» на страницах **нет** (удалён по просьбе заказчика).
- В `index.html` **нет выдуманных отзывов** и **нет разметки** `review` / `aggregateRating` — удалены до появления реальных данных.
- Ссылки «Отзывы на Яндекс.Картах» и «Отзывы в 2GIS» находятся в блоке контактов (`#contacts` / `.map-links`, якорь `#reviews` ведёт туда же) и выделены **световым акцентом** (класс `.map-links__hl` в `style.css`).

Безопасные способы добавить отзывы:

1. **Свои отзывы** — брать у клиентов прямо в сервисе, **с их согласия**, и публиковать в блоке контактов или отдельном разделе (подключите разметку `review` в JSON-LD с фактическими данными).
2. **Официальные виджеты.** У Яндекс.Бизнес («Виджет для сайта») и 2GIS есть легальные embed-виджеты отзывов — вставьте код в блок контактов (`#contacts`). Это разрешено правилами площадок.
3. **Ссылки на карточки** — «Отзывы на Яндекс.Картах» и «Отзывы в 2GIS» (сейчас так и сделано, ссылки подсвечены).
4. Когда появятся реальные отзывы — их же можно добавить в JSON-LD (`review` + `aggregateRating` с фактическими цифрами).

Про авторские права на текст и картинки: контент либо написан заново, либо взят с другого сайта **того же сервисного центра «Сибвоч»** (`sibwatch.ru`, ИП Ерёмкина Е. К.). Чужие тексты и изображения не используются. Фото работ и логотип должны принадлежать владельцу бизнеса.

## Что ОБЯЗАТЕЛЬНО заменить перед публикацией

1. **Домен** `https://remont-chasov-nsk.ru` → реальный (в `index.html`, 4 страницах услуг, `robots.txt`, `llms.txt`, `sitemap.xml`). Варианты: `remont-chasov-nsk.ru`, поддомен `remont.sibwatch.ru` или подпапка основного сайта.

3. **Отзывы** — раздел убран; ссылки «Отзывы на Яндекс.Картах / 2GIS» подсвечены в блоке контактов. Когда соберёте реальные отзывы (с согласия авторов) — добавьте их на страницу и в JSON-LD.

5. **Текст на странице «до/после»** — убрать строку про «фото-заглушки».
6. **Гарантия** — на сайте SibWatch расхождение: 24 месяца в «О магазине» против 12 в «Вопросах». Уточните и приведите к одному значению.
7. **Рейтинг в разметке** — `aggregateRating` намеренно отсутствует; добавляйте только с фактическими данными из Яндекс/2GIS (не завышайте).
8. **Форма заявки** — сейчас открывает WhatsApp; подключите реальный приём (backend, Formspree, CRM).

## Инструменты (автоматизация на OpenCode)

В папке `tools/` — три скрипта. Запуск (PowerShell):

```powershell
# 1. Аудит лендинга по чек-листу GEO/AEO (индексация, schema, NAP, alt, robots, свежесть цен)
powershell -ExecutionPolicy Bypass -File tools\seo-audit.ps1

# 2. Проставить цены из data\prices.json в таблицы + проверка свежести прайса
powershell -ExecutionPolicy Bypass -File tools\apply-prices.ps1

# 3. Сгенерировать JSON-LD для новой услуги
powershell -ExecutionPolicy Bypass -File tools\new-service-schema.ps1 `
  -Name "Полировка часов" -Slug "polirovka-chasov" `
  -Description "Полировка корпуса и браслета часов в Новосибирске" `
  -Faq "Сколько стоит полировка?|||Зависит от состояния корпуса.","Сохраняется ли покрытие?|||Да, восстанавливаем родиевое покрытие."

# 4. Проверить, рекомендует ли ИИ лендинг (монитор упоминаний бренда)
$env:AI_API_KEY="sk-..."   # ключ OpenAI-совместимого API (DeepSeek/OpenAI/OpenRouter)
powershell -ExecutionPolicy Bypass -File tools\ai-mentions.ps1 -Provider deepseek
powershell -ExecutionPolicy Bypass -File tools\ai-mentions.ps1 -Report
```

Как пользоваться ценами: заполните `data/prices.json` (ключ = текст услуги из таблицы, значение = цена, например `"500"`), затем запустите `apply-prices.ps1`. Скрипт заменит заглушки `от ___ ₽`, а незаполненные строки оставит с предупреждением. Поле `updated` отвечает за проверку свежести (порог 180 дней).

> Скрипты `.ps1` сохранены в UTF-8 **с BOM** — это нужно, чтобы русский текст корректно читался в Windows PowerShell 5.1. Если будете редактировать их в стороннем редакторе, сохраняйте с BOM.

## Как добиться, чтобы ИИ рекомендовал лендинг

1. **Индексация:** Яндекс.Вебмастер (важно для Алисы), Google Search Console и Bing Webmaster Tools (Bing влияет на ChatGPT). Отправьте `sitemap.xml`.
2. **Яндекс.Бизнес:** заполните карточку по адресу Писарева, 60 — услуги, цены, часы работы, фото. Алиса опирается на данные Яндекса.
3. **2GIS:** аналогично — карточка организации и отзывы.
4. **NAP-консистентность:** название, адрес, телефон должны совпадать везде.
5. **Отзывы:** систематически собирайте на Яндекс.Картах и 2GIS — сильный сигнал для ИИ.
6. **Проверка:** раз в 2–4 недели спрашивайте у ИИ «где заменить батарейку в часах в Новосибирске» и проверяйте, упоминается ли лендинг.
7. **Ссылки:** поставьте ссылку на лендинг с основного сайта, соцсетей и профилей организации.

### Монитор упоминаний в ИИ (`tools\ai-mentions.ps1`)

Задаёт список вопросов нейросети через OpenAI-совместимый API и проверяет, упоминается ли «Сибвоч» / SibWatch. Работает с DeepSeek, OpenAI, OpenRouter или своим endpoint — то есть заменяет платные сервисы мониторинга AI-видимости, но бесплатно.

- Вопросы лежат в `data\ai-questions.txt` (10 шт., можно дополнять).
- Без API-ключа скрипт не падает: он печатает список вопросов для ручной проверки в ChatGPT / DeepSeek / Алисе.
- Результаты пишутся в `data\ai-mentions-log.csv` (дата, провайдер, модель, вопрос, факт упоминания, позиция, сниппет).
- Сводка по накопленному логу: `-Report`. Запускайте раз в 2–4 недели и следите за динамикой.

## Цифровой след (внешние упоминания)

Это то, что нельзя сделать из кода — но именно это сильнее всего влияет на рекомендации ИИ. Чем чаще «Сибвоч» упоминается на авторитетных площадках, тем выше шанс, что нейросеть назовёт его первой:

1. **Яндекс.Карты** — регулярно собирайте свежие отзывы (Алиса опирается на Яндекс).
2. **2GIS** — карточка + отзывы.
3. **Flamp, Otzovik, Zoon** — отзывы с упоминанием услуг.
4. **VC.ru / профильные СМИ / местные форумы** — экспертные статьи о ремонте часов со ссылкой на лендинг.
5. **Единый NAP** — название, адрес и телефон должны совпадать везде **до буквы** с данными на лендинге.
